# Navo 0.6.0

## 新增功能

- 新增 Command Code GOAT Plan 接入，同步模型、5 小时／周额度窗口、月剩余与充值／免费额度。
- 支持账号级模型 ID 映射，提供精确匹配、前缀通配符和兜底规则；故障切换时按目标账号重新映射。
- 新增「可用模型」列表，可搜索模型、供应商与账号，查看各来源的实际调用模型，并逐模型复制 Kimi Code 配置。
- macOS 新增请求期间阻止系统休眠的实验性功能，支持延迟恢复及仅连接电源适配器时启用。
- 应用更新弹窗展示新版本更新内容。

## 问题修复

- 账号认证使用系统网络设置，改善桌面代理环境下的连接兼容性。
- 修复概览刷新时的加载闪烁，保留已有数据并为数值更新添加滚动过渡。
- 隔离源码运行与安装版的数据目录，避免开发数据影响已安装版本；源码运行使用独立的 Navo Dev 目录。
- 关闭认证测试使用的数据库，修复 Windows 构建中的文件占用问题。

## 其他改进

- 模型性能按实际调用的上游模型合并统计，映射别名与同模型直连请求统一汇总。
- 请求记录增加模型品牌图标与映射目标，首字和总耗时分行展示并标记延迟区间。
- 明确 Kimi 本地登录态导入与请求休眠保护的 macOS 支持范围。
- 更新 README 的供应商、模型配置导出、更新流程与数据存储说明。
