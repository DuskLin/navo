# Navo 0.5.0

## 新增功能

- 支持导入本地 Codex 和 Kimi Code 登录态，自动刷新认证；Kimi OAuth 默认仅允许 Kimi UA 调度。
- 新增 MiniMax Token Plan 中国区／国际区接入，同步模型、额度与重置时间。
- 支持自定义供应商 Base URL 与 API Key，可自动获取模型或仅手动配置。
- 支持手动批量添加模型、逐模型协议测试，并记录测试耗时与上游用量。
- 请求记录展示入站与实际上游路径，便于排查协议转换。
- 远程仪表盘支持携带访问码的自动登录链接与公网二维码分享，补齐 Codex、MiniMax 额度展示。

## 问题修复

- 改进上游 SSE 响应识别，修复 Codex 协议转换与 MiniMax 思考、流式响应适配。
- 完全未知的 Token 用量不再纳入用量统计，明确区分未知值与上游报告的零用量。
- 修复模型列布局，完善账号供应商校验与空用量展示。

## 其他改进

- 请求摘要仅保留最近 90 天，自动清理过期记录；列表隐藏 Request ID。
- 无额度或余额数据的账号不再显示额度卡片，仍可在账号管理中配置与调用。
- 统一仪表盘页头布局，优化手机端供应商筛选标签。
- 更新 README 功能说明、统一网关首图与章节布局，详细使用说明支持折叠查看。
